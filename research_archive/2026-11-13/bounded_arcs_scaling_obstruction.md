# Bounded arcs on typical diagonals fail

13 November 2026. Problem 001. Status labels as in the other notes of this folder: nothing here is in the paper. "Audit" means a separate line-by-line check by a second reader who derived the critical steps again.

Not audited yet.

# Result

## Status

obstruction

## Summary

Not proved, and probably false as stated. A rigorous scaling argument shows that the bounded-arc target with constant delta_0 forces every finite subset of every Pell set S^inf_{T'} (no height cutoff) to have Diophantine constant at least delta_0. An exact covering certificate (T' = 30305, 143 distances) puts that constant at most 247/5000, so the target fails for every delta_0 >= 0.0494. The data and the random model point to inf_{T'} delta(S^inf_{T'}) = 0, which would make the target false outright. An r-term extension of (three-term theorem) cannot change this, and with it sum_T chi(G_T) stays O(h log h / log log h).

## Statements

NOTATION (as in the setting). h >= 4, A_h = ceil(h/2), K = floor(h/2). For odd T: s = (T-1)/2, I_T = [max(0,-s), min(A_h,K-s)), n_T = |I_T|. Q(T,d) = 20d^2 + 4Td + T^2 = (T+2d)^2 + 16d^2. S_T(h) = { d != 0 : Q(T,d) = L^2, 0 < L < h }, D_T(h) = { |d| : d in S_T(h), |d| < n_T }, k_T = |D_T(h)|. ||x|| = distance to the nearest integer.
For an odd T' >= 1, put S^inf_{T'} = { d != 0 : Q(T',d) is a perfect square } (no height cutoff). For a finite nonempty A in S^inf_{T'}, Lambda(A) = max_{d in A} sqrt(Q(T',d)), and delta(A) = max over real x of min_{d in A} ||x d||. The maximum exists because the function is continuous and periodic, and delta(A) depends only on |A| = { |d| : d in A }. Call A delta-covering when every real x has some d in A with ||x d|| < delta. Equivalently delta(A) < delta.

THEOREM A (scaling obstruction; proved). Let T' >= 1 be odd, A in S^inf_{T'} finite and nonempty, Lambda = Lambda(A), and delta_0 > delta(A). Let h >= 2040 Lambda, and let E be any set of odd offsets such that every odd T > 0 with n_T >= 1 and T not in E has a real theta with ||theta e|| >= delta_0 for all e in D_T(h). Then
  sum_{T in E} k_T(h) >= (h / (272 Lambda)) * log(h / (2040 Lambda)).
In particular sum_{T in E} (k_T + 1) / h -> infinity as h -> infinity.

COROLLARY A1 (what the target needs; proved). Suppose some delta_0 > 0 and some C have the following property. For every h there is a set E_h of odd offsets with sum_{T in E_h} (k_T + 1) <= C h such that every diagonal T outside E_h admits theta with ||theta d|| >= delta_0 for all d in D_T(h). Then delta(A) >= delta_0 for every odd T' and every finite A in S^inf_{T'}. Equivalently delta* := inf_{T'} delta(S^inf_{T'}) >= delta_0 > 0, where for infinite D, delta(D) = sup_x inf_{d in D} ||x d||, which equals the limit of delta(A_n) along finite A_n increasing to D (by compactness).

COROLLARY A2 (the ratio criterion must blow up; proved). Under the hypotheses of Theorem A, take any T in the set B = { t T' : t odd, t Lambda < h, t T' <= h/2 }, any delta in (delta(A), 1/2] and any m >= 1. The ratios of criterion (12) of continuation_arc_parity_riesz.md satisfy, for D = D_T(h),
  sum_{d in D} Z_{D \ {d}} / Z_D >= 1 / (2 sqrt(m) sin^{2m}(pi delta)).
With the certificate C1(b) below and delta = 247/5000, the right side is at least 41.9^m / (2 sqrt m). Hence no bound of the form R_D(m) <= e^{c m} with c < 3.7 holds on these diagonals, and their total mass sum k_T is superlinear by Theorem A.

CERTIFIED COMPUTATION C1 (finite exact checks by script; no proof log beyond the scripts).
(a) T' = 1045 = 5*11*19, A = S^inf_{1045} restricted to L <= 60000: 61 distances, max 13299, Lambda = 59015. A is 413/5000-covering, so delta(A) < 0.0826. Checked in exact rational arithmetic as an open cover of [0,1/2] by the intervals ((j - delta)/a, (j + delta)/a). Restricted to L <= 6000 (31 distances, Lambda = 5225), A is 143/1250-covering, so delta(A) < 0.1144.
(b) T' = 30305 = 5*11*19*29, A = S^inf_{30305} restricted to L <= 606100: 143 distances, max 135850, Lambda = 594605. A is 247/5000-covering, so delta(A) < 0.0494. The cover check is exact. The set A was rebuilt by a second, independent enumeration over L (X = 10d + T', X^2 = 5L^2 - 4T'^2), which gave the same 143 distances. A float test over 4*10^6 random theta found max_theta min_a ||theta a|| = 0.04823.
CONSEQUENCE (proved from C1(b) and Corollary A1): the bounded-arc target fails for every delta_0 >= 247/5000. Any version that could hold needs delta_0 < 0.0494, that is, at least 21 arc classes on the typical diagonals.

PROPOSITION R (what an r-term extension of (three-term theorem) would give; the implication is proved, the hypothesis is not). Call a relation of T nondegenerate when it has distinct d_1..d_r in S_T, integer coefficients 0 < |c_j| <= Bc, sum c_j d_j = 0, odd sum c_j, and sum_{j in J} c_j (10 d_j + T) != 0 for every proper nonempty J. Assume H(r,Bc): summed over T, the number of nondegenerate relations is at most C(r,Bc) h. Then for each fixed K, sum_{T: k_T <= K} beta_odd(T,h) <= sum_{r <= K} C(r, m(K)) h. Combined with (17) of the parity note on those diagonals and with (local sparsity bound) (Alon, Krivelevich, Sudakov) on the rest, this gives sum_T chi(G_T) = O(h log h / log log h). That is the same order as (local sparsity bound), with no improvement for any choice K = K(h). (H(r,Bc) for r <= 3, Bc = 1 is (three-term theorem). For r >= 4 it is NOT proved; see the gaps.)

NOT PROVED: the target (bounded arcs outside a set of total cost O(h)); delta* = 0 (which would refute the target for every delta_0); sum_T chi(G_T) = O(h); any bound o(h log h / log log h).

## Proofs

0. SUMMARY OF THE ROUTE. The target was a constant delta_0 and a single rotation per diagonal for all diagonals outside a set E of total cost O(h). Diagonals divisible by a fixed T' contain a scaled copy of any finite piece of the infinite Pell set S^inf_{T'}. Those diagonals carry a positive fraction, about 1/Lambda, of the superlinear mass sum_T k_T. So the target forces a uniform Diophantine property of all the sets S^inf_{T'}. Computation shows that this property fails at every level above 0.0494, and that the level keeps falling as T' gains split prime factors. The random model predicts it tends to 0. So the right linear target is (missing estimate (E))(E), M_T <= C(1 + k_T / log h), which Theorem A does not touch, and not bounded arcs.

1. LEMMA 1 (scaled copies). Let T' >= 1 be odd, A in S^inf_{T'} finite, Lambda = Lambda(A), t >= 1 odd, T = tT', and suppose t Lambda < h and T <= h/2. Then t|A| := { t|d| : d in A } is contained in D_T(h).
Proof. Let d be in A with Q(T',d) = L^2, L >= 1. Q is homogeneous of degree 2 in (T,d), so Q(T, td) = t^2 Q(T',d) = (tL)^2 with 0 < tL <= t Lambda < h. Also td != 0, so td is in S_T(h). For the cutoff, any e in S_T(h) with Q(T,e) = L_e^2 satisfies 16e^2 <= (T+2e)^2 + 16e^2 = L_e^2, so |e| <= L_e/4 < h/4. For odd T > 0, s = (T-1)/2 >= 0, so max(0,-s) = 0, and K - s <= K <= A_h, so n_T = K - s = floor(h/2) - (T-1)/2 >= (h-1)/2 - (T-1)/2 = (h-T)/2 >= h/4 when T <= h/2. Hence |td| < h/4 <= n_T and t|d| is in D_T(h). QED.

2. LEMMA 2 (mass on multiples of T'). For Y >= 1 let N(Y) be the number of triples (a,y,L) of positive integers with y odd, 16a^2 + y^2 = L^2 and L < Y. Let T' >= 1 be odd and h >= 3 T' Y. Then sum over odd t < 1.12 Y of k_{tT'}(h) >= N(Y).
Proof. Take a triple (a,y,L) and put t = y + 2a (odd, because y is odd) and e = -T'a. Then Q(tT', e) = T'^2 Q(t,-a) = T'^2 ((t-2a)^2 + 16a^2) = T'^2 (y^2 + 16a^2) = (T'L)^2, with 0 < T'L < T'Y < h, so e is in S_{tT'}(h). By Cauchy-Schwarz, y + 2a = 1*y + (1/2)(4a) <= sqrt(5/4) L < 1.12 Y, so tT' < 1.12 T'Y < h/2 and, as in Lemma 1, n_{tT'} >= h/4 > T'L/4 >= T'a = |e|. So T'a is in D_{tT'}(h). For fixed t, different triples with y + 2a = t have different a, because y = t - 2a and L are then determined. So they give different elements T'a of D_{tT'}(h). Summing over t gives the claim. QED.

3. LEMMA 3. For Y >= 600, N(Y) >= (Y/80) log(Y/600).
Proof. Let P(Z) be the number of pairs u > v >= 1 with gcd(u,v) = 1, u - v odd and u^2 + v^2 < Z. Claim: P(Z) >= Z/40 for Z >= 600. Let R = floor(sqrt(Z/2)). Then R >= 17, and every pair with 1 <= v < u <= R has u^2 + v^2 < 2R^2 <= Z. There are sum_{u <= R} floor(u/2) >= R(R-1)/4 such pairs with u - v odd. A common divisor greater than 1 of such a pair is odd, so the pair has a common odd prime factor q. For each q at most R^2/(2q^2) pairs have both entries divisible by q, and sum over odd q >= 3 of 1/(2q^2) <= (pi^2/8 - 1)/2 < 0.117. So P(Z) >= R(R-1)/4 - 0.117 R^2 >= 0.133 R^2 - 0.25 R >= 0.118 R^2 for R >= 17. Since sqrt(Z/2) - 1 >= sqrt(Z)/2 for Z >= 24, R^2 >= Z/4, which gives P(Z) >= 0.0295 Z >= Z/40.
Each pair (u,v) and each odd g >= 1 give the triple a = guv/2 (an integer, because uv is even), y = g(u^2 - v^2) (odd), L = g(u^2 + v^2): 16a^2 + y^2 = g^2 (4u^2 v^2 + (u^2 - v^2)^2) = L^2. Different (g,u,v) give different triples: gcd(2uv, u^2 - v^2) = 1, so g = gcd(4a, y), and (u,v) is recovered from the primitive triple. So N(Y) >= sum over odd g <= Y/600 of P(Y/g) >= (Y/40) sum_{odd g <= G} 1/g with G = Y/600 >= 1. Also 1/g >= (1/2) int_g^{g+2} dx/x for every odd g, so sum_{odd g <= G} 1/g >= (1/2) log(G+1) >= (1/2) log G. QED.

4. PROOF OF THEOREM A. Put delta_1 = delta(A) < delta_0 and B = { tT' : t odd, t Lambda < h, tT' <= h/2 }. Let T = tT' be in B and theta real. Apply the definition of delta(A) at x = t theta: some d in A has ||t theta d|| <= delta_1 < delta_0, and t|d| is in D_T(h) by Lemma 1. So no theta is good for D_T(h) at level delta_0, and T must lie in E. Hence B is contained in E. (Each T in B has n_T >= h/4 >= 1.)
Now Q(T',x) >= 0.8 T'^2 for all real x (the minimum is at x = -T'/10), so Lambda >= sqrt(0.8) T' >= 0.89 T'. Put Y = h/(3.4 Lambda). Then 3T'Y <= 3.37 Lambda Y < h, so Lemma 2 applies. Every odd t < 1.12 Y satisfies t Lambda < 1.12 h/3.4 < h and tT' < 1.12 T' Y < h/2, so all the offsets tT' counted in Lemma 2 lie in B. Since h >= 2040 Lambda gives Y >= 600, Lemmas 2 and 3 give sum_{T in E} k_T >= sum_{T in B} k_T >= N(Y) >= (h/(272 Lambda)) log(h/(2040 Lambda)). QED.

5. PROOF OF COROLLARY A1. Suppose some finite A in S^inf_{T'} has delta(A) < delta_0. Theorem A applies to E_h for large h and gives sum_{E_h} (k_T + 1) >= c_A h log h, which contradicts the bound C h. For the reformulation with delta*: if A_n increases to D and delta(A_n) >= c for all n, choose x_n with min_{A_n} ||x_n d|| >= c. A limit point x of (x_n mod 1) has ||x d|| >= c for each d in D, because {x : ||x d|| >= c} is closed and contains x_n for all large n. So delta(D) = lim delta(A_n), and delta* = inf over finite A. QED.

6. PROOF OF COROLLARY A2. Fix T in B and delta in (delta(A), 1/2]. By the proof of Theorem A, no theta has ||theta e|| >= delta for all e in D = D_T(h). Criterion (12) of continuation_arc_parity_riesz.md, which is valid for every finite D, states that b_m(delta) sum_d Z_{D\{d}}/Z_D < 1 implies such a theta exists, with b_m(delta) = 2 sqrt(m) sin^{2m}(pi delta). So sum_d Z_{D\{d}}/Z_D >= 1/b_m(delta). For delta = 247/5000: sin(pi delta) = 0.15457..., and 0.15457^{-2} > 41.8. QED.

7. COMPUTATION C1. Scripts are in the script folder scripts_typical_relations/. Each run used py and took less than 60 seconds.
- cover.py T' Lmax [x] [iters] builds A = { |d| : Q(T',d) = L^2, L <= Lmax } by a direct search over |d| <= Lmax/4 + 1 (the full range, since |d| <= L/4). It bisects delta(A) with a float cover test, and with x it runs an exact Fraction sweep. The sweep checks that the intervals ((j - P/Q)/a, (j + P/Q)/a), a in A, 0 <= j <= a/2 + 1, form an open cover of [0,1/2]. Since ||(-x)a|| = ||xa||, a cover of [0,1/2] covers the circle.
- verify2.py rebuilds A by a different loop (over L, X^2 = 5L^2 - 4T'^2, X = +-T' mod 10, d = (X - T')/10) and runs a random-theta float test. For T' = 30305: same k = 143 and max 135850, and random max-min 0.04823 < 0.0494. verify.py does the same for T' = 1045: all 61 distances are members, Lambda = 59015, and the random max-min 0.08229 < 0.0826. For M_T > 4 it is 0.22 up to 0.64, and the largest M_T grows from 7 to 11. These M_T come from a search over theta = a/q and are upper bounds, so the numbers are evidence, not certified lower bounds. They grow roughly linearly in log h, as the target's failure predicts.

8. WHY delta* = 0 IS EXPECTED (heuristic, not proved). For squarefree T' with s split primes, S^inf_{T'} is a union of about 3^s affine Fibonacci-type orbits, X_j = Tr(kappa^2 phi^{2j+1}) with d = (X - T')/10, each lacunary with ratio phi^2. Each multiplicative scale [N, phi^2 N] therefore holds about 3^s distances, and a theta refined from scale to scale survives with probability about (1 - 2 delta)^{3^s} against phi^2 branches. This predicts delta(S^inf_{T'}) of order 3^{-s}, hence delta* = 0. If so, Corollary A1 refutes the target for every delta_0 > 0. The computed decrease from 0.27 to 0.049 as s goes from 1 to 3 fits this picture, though more slowly than 3^{-s}. The same model gives M_T of about 1 + 2k_T/ln h and sum_T M_T = O(h). So the linear total is not obstructed; only its bounded-arc form is.

9. r-TERM RELATIONS (the method of the three-term theorem). The local analysis of (three-term theorem) extends formally. At a prime p dividing T exactly once with p > Bc, the type vector sigma(P) in {-1,0,1}^r of a primitive configuration has at least two nonzero entries: if only entry j0 is nonzero, then c_{j0} Tr(beta_{j0}) is in pZ while Tr(beta_{j0}) is not in P, so p divides c_{j0}. Elimination at the type sigma with the largest P_sigma gives Tr(kappa^2 Omega) = c0 P with Omega = sum_{sigma_j = 1} c_j nu_j + sum_{sigma_j = -1} c_j nu_j' and c0 P = sum_{sigma_j != 0} c_j (10 d_j + T). There are two cases. If sigma has no zero entry, c0 P = c_+ T, which is nonzero because the coefficient sum c_+ is odd; this is where the parity hypothesis enters. If sigma has zero entries, c0 != 0 is exactly the nondegeneracy condition for J = { j : sigma_j != 0 }. (The reflection relation d + d' - (-T/5) = 0 is degenerate in this sense, since X_d + X_{d'} = 0.) Reconstruction and counting then go as in (three-term theorem)(3.7)-(3.10), with 3^r/2 types, P_sigma >= T1^{2/3^r}, and the factor (tau(m)^2 log x)^r. The expected result is a power saving x^{1 - 2/3^r} (log x)^{O(r)} for primitive configurations, and so H(r,Bc) with C(r,Bc) = exp(O(r log r + r log Bc)). I did not write this out or re-read it line by line, so H(r,Bc) for r >= 4 remains a claim. Note that H(2,Bc) has C(2,Bc) >= c log Bc: the reflection pairs (e0/g) d0 - (d0/g) e0 = 0 of the odd-deletion note are nondegenerate, have odd sum and number at least c h log Bc.

10. PROOF OF PROPOSITION R (the implication only). For a set E of distances, a relation with odd coefficient sum and |c| <= m splits into nondegenerate pieces, one of which has odd sum. If the support splits into J and its complement with sum_J c_j X_j = 0, then sum_{J^c} c_j X_j = c_+ T. Both parts are relations in d, because sum_J c_j d_j = -T c_J / 10 and integrality are inherited (I checked this case only for the X-form: it needs 10 | T c_J, which holds when 5 does not divide T; for 5 | T this step needs one more line that I have not written). So deleting one distance from each nondegenerate odd relation of cap m(K) makes condition (6) hold, and beta_odd(T) <= the number of such relations whenever k_T <= K (m is nondecreasing). Then (17) of the parity note gives at most 4(beta_odd + 1) classes on those diagonals. On diagonals with k_T > K, (local sparsity bound) gives chi <= C0 k_T / log k_T. In total: sum chi <= 4h + 4 h sum_{r <= K} C(r, m(K)) + C0 sum_{k_T > K} k_T / log k_T. The last sum is O(h log h / log log h) for any K, by the proof of (local sparsity bound): its terms with k_T >= (log h)^{1/2} already give that order. So the total is O(h log h / log log h), the same order as (local sparsity bound). Heuristically the mass of sum k_T sits at k_T near (log h)^{1.65}, so no choice of K improves the order; that last point is not proved. To reach the mass diagonals by parity Riesz you would need relations of length about k_T with caps about log k_T. These are not bounded-r statements, and on central diagonals the deletion cost is superlinear in total (odd-deletion note, Omega(h log log log log h)). By Theorem A no argument at all gives bounded arcs there unless delta* > 0.

11. WHAT THE TARGET SHOULD BE INSTEAD. Theorem A forces only M_T >= 1/delta(A), a constant, on the offsets in B. It is consistent with (missing estimate (E))(E), M_T <= C(1 + k_T / log h), and with sum_T M_T = O(h). In ratio form, Corollary A2 shows that constant delta needs R_D(m) <= e^{c m} with c < 3.7, which fails. The useful regime is delta = c log h / k_T with m of order log h / log(k_T / log h). There, (13) needs only R_D(m) <= h^{O(1)}, which Theorem A does not contradict.

## Gaps

- The target itself is not proved, and it is refuted only for delta_0 >= 247/5000 (Corollary A1 plus certificate C1(b)). The full refutation, for every delta_0 > 0, needs delta* = inf_{T'} delta(S^inf_{T'}) = 0. That rests on the random/branching model and on the computed decrease 0.27 -> 0.049 as the number of split prime factors goes from 1 to 3. It is not proved.
- Theorem A is asymptotic: with Lambda = 594605 the superlinear cost c h log h / Lambda exceeds C h only for astronomically large h (log h >> 272 Lambda). It says nothing at computable heights.
- The certificates C1 are exact rational sweeps produced by one script (cover.py). The distance sets were rebuilt independently (verify2.py, verify.py) and float random-theta tests agree, but there is no separate exact checker and no proof log.
- Proposition R: the hypothesis H(r,Bc) for r >= 4 is not proved. Section 9 is a sketch of how (three-term theorem) extends, with the degenerate case handled by definition. The splitting step of Section 10 (a degenerate odd relation contains a nondegenerate odd one) was checked only when 5 does not divide T; the case 5 | T needs another line.
- (three-term theorem) and (local sparsity bound) are themselves still under audit (they were unaudited at the time). Proposition R's total O(h log h / log log h) inherits that status and the Alon-Krivelevich-Sudakov citation.
- The claim that no choice of K in Proposition R improves the order depends on the heuristic location of the mass of sum k_T (k_T near (log h)^1.65). It is not proved.
- Theorem A obstructs only the single-rotation, bounded-arc formulation. It does not bound sum_T M_T or sum_T chi(G_T) from below beyond a linear term, and multi-dimensional Bohr colourings are untouched.
- No independent audit of Theorem A or Lemmas 1-3. I re-read them line by line, including the cutoff n_T >= (h-T)/2 for T > 0 and the constants 1.12, 3.4, 272, 2040.

## Missing estimate

Two estimates decide the route. (1) delta* = inf over odd T' of delta(S^inf_{T'}) = 0: for every delta > 0 some odd T' and finite A in S^inf_{T'} are delta-covering. With Corollary A1 this refutes the bounded-arc target for every delta_0. The computations give delta* < 0.0494. (2) The useful positive target that Theorem A leaves open: M_T <= C(1 + k_T / log h), for example through the ratio criterion (13) with delta = c log h / k_T and m of order log h / log(k_T / log h). This needs only R_{D_T}(m) <= h^{O(1)} at such m, and with sum_T k_T = O(h log h) it gives sum_T M_T = O(h).

## Next steps
