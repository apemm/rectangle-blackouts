# Heavy diagonals and a light-heavy split of the label scaffold

13 November 2026. Problem 001. Status labels as in the other notes of this folder: nothing here is in the paper. "Audit" means a separate line-by-line check by a second reader who derived the critical steps again.

Result: a label scaffold with no corner triple and no rival pair in width O(h^2 (log h)^1.369). Mixed quadruples and the sea are not treated. Not audited yet.

# Result

## Status

partial

## Summary

Heavy diagonals are a positive fraction of labels for every fixed B < chi(Gamma). Splitting rigid light regions (B ~ (log h)^theta) from a degree-weighted random region for heavy labels gives a label scaffold with no corner triple and no rival pair in width O(h^2 (log h)^1.369) with the menu {2,4,8,12,20}, and O_eps(h^2 (log h)^(1.3108+eps)) with larger menus. This is proved modulo audited inputs, with no second audit yet. For m_h the same exponent follows only under two hypotheses: a sea for rigid regions, and a degree-scaled T1. With the paper's tau*^2 placement there is no gain.

## Statements

NOTATION. A = ceil(h/2), K = floor(h/2), q_h = AK. Labels (i,j) lie on diagonals T = 2(j-i)+1, s = (T-1)/2, with n_T labels (n_T <= A). Menu F = {s_1..s_m} of even strides s_i = 2 sigma_i with Delta_i = sigma_i^2 + 1, no subset product a square (for example {2,4,8,12,20}: Delta = 2,5,17,37,101). k_T^(sigma) and G_T^(sigma) are as in stride_menu.md, Derivation 2. kappa_T := min_i k_T^(sigma_i). A diagonal is B-HEAVY if kappa_T >= B (this contains every T with min_i chi(G_T^(sigma_i)) > B, because chi <= k+1). H_d(B) = number of B-heavy diagonals; H(B) = number of labels on them, so H(B) <= A H_d(B). E_F(a) := ((1 + 3^(a/m))/2)^m, beta_m = E_F(1) - 1.
LABEL SCAFFOLD: one double per label (rows 2i+1 and 2j+2) at distinct columns, with no corner triple (3 corners of a tilted rectangle of the strip) and no rival pair among label points. Mixed quadruples and the sea are NOT included.

THEOREM 1 (upper count; proved). For h >= 4:
(a) H_d(B) <= (C_F h (log h)^(beta_m) + 1)/B, so H(B) <= A(C_F h (log h)^(beta_m) + 1)/B.
(b) For every a > 0 there is C = C(a,F) with H_d(B) <= C h (log h)^(E_F(a)-1) B^(-a) for all B >= 1. Equivalently, heavy labels are at most C h^2 (log h)^(E_F(a)-1) B^(-a).
(c) Limit of the method: E_F(a) > 1 for every a > 0, and inf_a (E_F(a)-1)/a = (ln 3)/2. So the bounds of (a) and (b) give a heavy fraction o(1) only for B >= (log h)^(0.549+eps). For fixed B they are not even bounded by 1.

THEOREM 2 (lower count; proved). (a) Stride 4: for odd c with 1 <= c <= h/3826, the diagonals T = +-1045c have chi(G_T^(2)(h)) >= 5, so H^(stride 4)(4) >= 9.4e-5 h^2 - h, a positive fraction (about 3.8e-4 of q_h). By the SAT bound chi(G_1045) >= 7 (computational, from limit_graph_gamma.md), the same holds for B = 6 with a smaller constant.
(b) General menu: let X_sigma = sup_T chi(Cay(Z, D_T^(sigma,inf))). For every B < min_i X_(sigma_i) there are c_B > 0 and h_B with H(B) >= c_B h^2 (heaviness taken as min_i chi > B) for h >= h_B. Every stride has an edge, so B = 1 qualifies for every menu. If chi(Gamma) = inf (stride 4), then for every B the stride-4 heavy labels are at least c_B h^2.

PROPOSITION R (rigid region, any even stride; proved from audited Lemma 4 and Proposition 1'). Fix an even s = 2 sigma, a prime p with max(20h,(s^2/2+4)h) < p <= 2max(20h,(s^2/2+4)h), and a family of classes. Each class is a subset of one diagonal, independent in G_T^(sigma)(h), and each diagonal has at most B classes. Let 2^nu be the least power of 2 with 2^(1+2v_2(sigma)+nu) >= K. Put class c at columns s(i + p m_c), with distinct integers m_c satisfying p m_c = s_c - kappa (mod 2^nu). Then the label points have no tilted right angle and no rival pair, and some such m_c fit in width < s(A + p(h+K)B). For s = 4 this is at most 240 B h^2 + 2h + 2.

LEMMA G (gluing; proved). Let B_1..B_r be strip configurations that are row-1 singletons outside windows U_k, where consecutive windows are more than 2W_h apart, and each B_k contains no obstruction. Then the union (B_k on U_k plus 2W_h on each side, row 1 elsewhere) contains no obstruction. The same holds for the label-only scaffold property.

LEMMA P (degree-weighted placement of doubles; proved). Let S be a set of parity edges and Delta = max over rows y of #{e in S : y in e}. Put N = ceil(816 Delta h (1 + ln h)^2). Then there are distinct columns X_e in [1,N] such that the label points of S contain no corner triple and no rival pair. For S = all edges (Delta = A), this gives an elementary scaffold of width <= 408 (h+1) h (1+ln h)^2 + 1.

THEOREM 3 (scaffold width; proved modulo audited inputs). For every menu F as above and every a > 0, for h >= 4 the q_h labels admit a label scaffold of width <= C(F,a) h^2 (log h)^(theta_F(a)), with theta_F(a) = (1 + E_F(a))/(1 + a). The optimised exponents theta_F = inf_a theta_F(a) are: m = 1 (stride 4 only): 1.4967 (a = 0.91); m = 2: 1.4295; m = 3: 1.3987; m = 5 ({2,4,8,12,20}): 1.3690 (a = 1.32); m = 10: 1.3425; m -> inf: 1.3108 (a = 1.58). Since valid menus exist for every m, the scaffold width is O_eps(h^2 (log h)^(1.3108+eps)). The light threshold is B = ceil((log h)^(theta_F(a))). The best earlier scaffold bounds were T1, h^2 log^2 h (loglog h)^C (a full board), and the rigid layout alone, h^2 max_T kappa_T = h^(2+o(1)).

THEOREM 4 (m_h; CONDITIONAL). Assume (S): every rigid region of Proposition R of scaffold width W extends to an obstruction-free strip configuration with singletons elsewhere and row-1 tails, of width <= C(W + h^2) (the route's assumption: a sea of cost O(1) per label). Assume also (H1'): every set S of parity edges with maximum row degree Delta extends to such a configuration of width <= C Delta h (log h)^2 (loglog h)^C' (T1 scaled by degree; for S = all edges this is T1). Then m_h <= C h^2 (log h)^(theta_F) (loglog h)^C', so for example m_h = O(h^2 (log h)^1.369 (loglog h)^C') with the 5-stride menu. Under (S) alone, with the paper's Proposition partial (cost c0 tau*(h)^2 per edge) for the heavy region, the optimum is h^(2 + (4 ln 2 + o(1))/((1+a) lnln h)) for each fixed a. That is worse than T1, so routes (ii) and (iii) give nothing for m_h without (H1').

PROPOSITION 5 (what blocks O(h^2) on this route; proved). (a) Rigid lower bound: a stride-4 rigid region that holds a diagonal with M classes has width >= 5h^2(M-1) (rigid note, Theorem 5 converse). (b) By Theorem 2, for every fixed B < chi(Gamma) at least c_B h^2 labels are heavy. So if chi(Gamma) = inf, width O(h^2) on the route 'rigid light + other heavy' needs an O(1)-per-label method on a positive fraction of labels. Lemma P costs Theta(log^2 h) per label at positive density, because its first moment is that large. With the Lemma-2 majorant, exponents below 1.3108 cannot come from this route.

NOT PROVED: m_h = O(h^2); any bound on m_h below T1 without (S) and (H1'); any lower bound above q_h; a scaffold without mixed quadruples in width below log^2; chi(Gamma) finite or infinite.

[5] PROOF OF LEMMA P. Choose the X_e independently and uniformly in [1,N].
Pair events (2 doubles e, f, offset x = X_f - X_e). Distinctness forbids 1 value. A corner triple uses 3 distinct points, and its two legs have nonzero coordinates. So the vertex Q0 shares a column with neither Q1 nor Q2, and if Q1 and Q2 share a column they are the 2 points of one double. With Q0 = (0,c), c in e, and the vertical diagonal f at x, we need x^2 = (r_f - c)(c - s_f): at most 2 values for each c, so at most 8 values over both roles. Rival pair (rows c in e, c' in f of different parity): by Lemma count(c), at most 2 tau(|c-c'|^2) values. So at most G2(e,f) = 9 + 2 sum_{c in e, c' in f, c-c' odd} tau(|c-c'|^2) values are bad. (lemmaP_pairs.py checked this bound by brute force for h = 9, 12, 15, with the largest ratio bad/G2 = 0.235.)
Triple events (3 distinct doubles, one point each, rows y0, y1, y2, vertex Q0). By Lemma count(a), the offsets (x1,x2) satisfy x1 x2 = -(y1-y0)(y2-y0), which gives at most 2 tau(|y1-y0||y2-y0|) <= 2 tau(|y1-y0|) tau(|y2-y0|) vectors. So the probability is <= (that count)/N^2.
Sums. Let deg(y) <= Delta. Put D(h) = sum_{n<=h} tau(n) <= h(1+ln h) and E(h) = sum_{d<=h} tau(d^2) <= h(1+ln h)^2. The second bound holds because tau(d^2) = sum_{m|d} 2^omega(m) <= sum_{m|d} tau(m), so E(h) <= h sum_{ab<=h} 1/(ab). Since |S| <= A Delta <= h Delta, sum_{f in S} G2(e,f) <= 9h Delta + 2 sum_{c in e} sum_{c'} deg(c') tau(|c-c'|^2) <= 9h Delta + 8 Delta E(h) <= 17 Delta h (1+ln h)^2. For triples, fix one of the 6 role patterns, say e = Q0. Then sum over ordered (f,g) <= 2 sum_{y0 in e} (sum_{y1} deg(y1) tau(|y1-y0|)) (sum_{y2} deg(y2) tau(|y2-y0|)) <= 2 * 2 * (2 Delta D(h))^2. With 6 patterns the total is <= 96 Delta^2 D(h)^2.
Local lemma (general form, as in the proof of the paper's Lemma placement) with x_L = 2 Pr(E_L) bound. Per double, sum_{L containing e} x_L <= 34 Delta h(1+ln h)^2/N + 192 Delta^2 h^2 (1+ln h)^2/N^2 <= 1/24 + 1/3000 < 1/12 at N = 816 Delta h(1+ln h)^2. For |L| <= 3, sum_{L' meeting L} x_(L') <= 1/4, so x_L prod (1 - x_(L')) >= x_L/2 >= Pr(E_L). E_L depends only on {X_e : e in L}. So with positive probability no event occurs. []

[6] PROOF OF THEOREM 3. Fix a and B = ceil((log h)^(theta_F(a))).
LIGHT: each light T (kappa_T <= B-1) takes a stride sigma(T) with k_T^(sigma) = kappa_T. Greedy colouring of G_T^(sigma) gives <= k + 1 <= B classes. Proposition R, used once per stride, gives width <= C_F B h^2 with no tilted right angle and no rival pair.
HEAVY: the set S of labels on B-heavy diagonals has row degree Delta <= H_d(B). An odd row 2i+1 lies in labels (i, i+s), one for each heavy s, and an even row likewise. Lemma P gives width <= 816 H_d(B) h (1+ln h)^2 + 1 <= C h^2 (log h)^(E_F(a)+1) B^(-a) by Theorem 1(b).
GLUE: there are m+1 regions with gaps of 2W_h + 1 <= h^2/2 + 1 columns. A corner triple or rival pair spans <= W_h columns, so no label obstruction meets two regions.
Total <= C(B h^2 + h^2 (log h)^(E+1) B^(-a) + (m+1) h^2). Since E + 1 - a theta = (E+1)/(1+a) = theta, both main terms are O(h^2 (log h)^theta). The exponents in the table come from minimising over a (theta.py); for m -> inf, E_F(a) -> 3^(a/2). []

[7] PROOF OF THEOREM 4 (conditional). Apply (S) to each stride region and (H1') to the heavy region (Delta <= H_d(B)), with row-1 tails. Lemma G then gives an obstruction-free strip configuration whose doubles are the q_h distinct parity edges, in width C h^2 (log h)^theta (loglog h)^C'. Restricting it to columns 1..m for every m at least that width gives a valid blackout with m + q_h points, by the reduction lemma and the paper's truncation argument. With Theorem rowbound this bounds m_h. For the (ii) variant, Proposition partial gives width c0(n+4) tau*(h)^2 + 6h^2 + 4 for n heavy edges. Since tau*(h) = exp((2 ln 2 + o(1)) ln h/lnln h), balancing B against tau*^2 h^2 (log h)^(E-1) B^(-a) gives the stated h^(2 + (4 ln 2+o(1))/((1+a) lnln h)). That is worse than log^2 h for every fixed a.

[8] PROOF OF PROPOSITION 5. (a) is D1 of the rigid note (Derivation 2): the M classes of one diagonal sit in one progression of step 2^nu >= K/8, at spacing p > 20h, which is >= 5h^2(M-1) columns at stride 4. (b) is Theorem 2. For a positive-density set S, the first moment of rival-pair conflicts per double in a uniform placement is about sum_{c'} deg(c') tau(d^2)/N, and this is of order Delta h log^2 h / N because sum_{d<=h} tau(d^2) is of order h log^2 h (lower bound: ledger T11 (12)). So Lemma P's method needs N >= c Delta h log^2 h. This is a statement about the method, not a lower bound on m_h.

[9] ROUTE (i), PARTIAL RIGID RULE (analysis, not a theorem). With modulus 2^v = K/R, the survivors of Theorem 4(a) need a vertex-class slot gap t1 with t1/gcd(t1,T0) < R/8. Removing them by class shape forces every heavy class to avoid all gaps in [1, min(R/8, |T0|/294)), and also g t' for every divisor g of T0. This costs at least R/8 classes per heavy diagonal, and the greedy upper bound adds tau(T0)R/8 more. The region then needs about 2^v x (heavy diagonals per residue) x R/8 >= H_d R/8 positions, while the max term 2^v max kappa_T = K max kappa/R needs R >= max kappa_T = h^(o(1)). Both are worse than Lemma P's H_d h log^2 h. I found no way to make (i) competitive. Theorem 2(d) of the rigid note (classes of one diagonal never interact) allows a single-diagonal region at cost about h^2/2 + 160h chi_T. That costs Theta(h^3 c_B) over a positive-density heavy set.

## Missing estimate

On this route, with delta(B) := sup_h H_d(B)/h, the scaffold width is about h^2 min_B (B + delta(B) log^2 h). Theorem 2 gives delta(B) >= c_B > 0 for every B < chi(Gamma). So if chi(Gamma) = inf, O(h^2) needs a heavy-label method of O(1) per label on a positive-density family, which Lemma P cannot supply. If delta(B) <= B^(-a) held uniformly in h, the width would be h^2 (log h)^(2/(1+a)). The proved bound delta_h(B) <= (log h)^(E(a)-1) B^(-a) comes from Lemma 2, which treats every ideal generator in the box as giving a distance. The data show that this is very lossy for |T| close to h. Two estimates would sharpen the route: (1) a bound k_T^(sigma) <= g_sigma(T) w(h/|T|) with w(x) -> 0 as x -> 1, from equidistribution of ideal generators (Hecke angular characters) in the window (p^2+q^2)/|N| < h/|T|, which would shrink the heavy tail; (2) (H1') with the sea, that is, T1's weighted pair estimate scaled by the row degree, to turn the scaffold bound into a bound on m_h.
